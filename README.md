# 하루 세 번 날씨 안내 (뼈대)

| 시간대 | 내용 |
| --- | --- |
| 아침 | 출근길 체감온도·비 확률로 체크리스트 (우산, 겉옷) |
| 점심 | 날씨·대기질에 맞는 메뉴 추천 카드 |
| 저녁 | 퇴근길 날씨·대기질에 맞는 할 일 또는 위로 문구 |

날씨 데이터는 OpenWeather (현재 날씨, 3시간 예보, 대기질)를 씁니다.

## 실행

1. `pip install -r requirements.txt`
2. 이 폴더에 `.env` 파일을 직접 만들고 `OPENWEATHER_API_KEY=발급받은키` 한 줄을 적습니다.
3. `python main.py morning` (또는 `lunch`, `evening`. 생략하면 지금 시각으로 고릅니다)
